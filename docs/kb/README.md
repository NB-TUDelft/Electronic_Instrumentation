# Electronic Instrumentation Knowledge Base

These rules apply to any AI assistant (Claude Code, Cursor, Copilot, Codex, etc.) when generating, editing, or reviewing content in this repository (notebooks, README, prose, code comments, docstrings, commit messages, PR descriptions). This knowledge base is the single source of truth for maintainer and agent guidance; `AGENTS.md` (which `CLAUDE.md`, `CODEX.md` and `agents.md` link to) only points here.

**Reading it.** Read this index in full, then every section on the
*always read* list below, then go straight to the sections your task needs. Each
section is one file, small enough to read whole, and every entry links to it by
path. Groups run from most to least important (see "Order of this knowledge base"
under Rules), and the three-digit prefixes keep sections in that order on disk
as well.

**Changing it.** Edit the section files, never the list below: it is
generated from each section `# Title` and the `summary` and `always_read` in
its front matter. After adding, removing, renaming, or moving a section, run
`python3 docs/kb/housekeeping.py` to rewrite the list.
`python3 docs/kb/housekeeping.py --check` fails while the list is stale or a
file breaks the layout rules; run it before you commit a knowledge base change.
`python3 docs/kb/housekeeping.py --graph` refreshes the graphify graph edges
for the knowledge base, after `graphify update .`, so a query about code also
finds the sections that discuss it. "Order of this knowledge base" under Rules
holds those rules.

**Section numbers.** The moved text still refers to other sections by their
numbers in the old `AGENTS.md` (for example, "section 12"). Each summary below
ends with that number, so resolve such a reference from the summaries.

**Course**: why the course exists, what counts as good, and who the students are.

- [What this repository is](010-course/010-what-this-repository-is.md) (*always read*): The source for the NB2420 Electronic Instrumentation practicum manuals, published as a Jupyter Book (TeachBook); course goals in priority order, transferable lab skills first, then electronics fluency, then problem-solving based work; the audience of second-year Nanobiology students. AGENTS.md section 1 before the split.

**Rules**: how to work in this repository: its map, git synchronization, this knowledge base itself, and scope.

- [Repository map](020-rules/010-repository-map.md) (*always read*): Use the graphify graph for deeper knowledge of the repository, and set graphify up as a uv tool when the user agrees. AGENTS.md section 0 before the split.
- [Git synchronization](020-rules/020-git-synchronization.md) (*always read*): Before any repository work, fetch every remote, check branch, upstream, and worktree state, and bring the branch up to date by fast-forward or safe rebase; repeat before every push; stop and ask when integration is unsafe. AGENTS.md section 0.1 before the split.
- [Scope](020-rules/030-scope.md) (*always read*): The prose rules govern all prose in the repository, including historical content, unless the user strictly asked to keep it. AGENTS.md section 13 before the split.
- [Order of this knowledge base](020-rules/040-order-of-this-knowledge-base.md) (*always read*): Standing rule: the knowledge base is one file per section under docs/kb/, in groups (Course, Rules, Manuals, Authoring, Log books, Reference) ordered by three-digit prefixes; how to place new sections; the index generated by python3 docs/kb/housekeeping.py from each section title and front matter, and checked by its --check mode.

**Manuals**: the BASIC manual format, the ALPACA hardware platform, and the boundary with the textbook.

- [Manual structure (the BASIC format)](030-manuals/010-manual-structure-the-basic-format.md) (*always read*): Every weekly manual follows Background, Anticipate, Simulate, Implement and Investigate, Compare and Conclude, with task names, modes, and time budgets; pair and group work; the CORE, TRANSFERABLE, NICE, and OMIT plan tags. AGENTS.md section 2 before the split.
- [Hardware platform](030-manuals/020-hardware-platform.md): The ALPACA board and bench instruments; legacy test boards are phased out; schematics, not breadboard layouts; MicroPython, Belay, and LTspice; extra components go in a plan Bill of Materials. AGENTS.md section 4 before the split.
- [When the textbook covers a concept](030-manuals/030-when-the-textbook-covers-a-concept.md): The textbook under helpers/theory_part/ carries theory; a manual re-explains only what students trip on or the textbook does not cover, and always links to it. AGENTS.md section 7 before the split.

**Authoring**: naming, style, and the strict prose rules for everything written in this repository.

- [Naming conventions](040-authoring/010-naming-conventions.md): Notebook file names, internal working files (_*.md) and plan documents, manual titles, task labels and cross-references, and figure names. AGENTS.md section 5 before the split.
- [Style conventions](040-authoring/020-style-conventions.md) (*always read*): Voice and tone, math and units, figures, the admonitions used in this book, and the vibrant magenta inline TODO flag. AGENTS.md section 6 before the split.
- [Punctuation: no em or en dashes](040-authoring/030-punctuation-no-em-or-en-dashes.md) (*always read*): Do not use em or en dashes in prose, and do not substitute a hyphen; what to use instead, replacements for common dash idioms, and the self-check before saving. AGENTS.md section 10 before the split.
- [Other writing conventions](040-authoring/040-other-writing-conventions.md): Straight quotes, e.g. and i.e. with a comma, short sentences, and the instructional second-person voice in notebooks. AGENTS.md section 11 before the split.

**Log books**: the fillable log book entry that ships with every manual, how it reaches students, and how to write and check one.

- [Log book entries](050-logbooks/010-log-book-entries.md): One fillable log book entry per manual: where they live, how the typst block puts one in the download menu and editor, how to write a new entry from the manual Compare and Conclude tasks, the field and image rules that are easy to get wrong, and clean-build verification. AGENTS.md section 12 before the split.

**Reference**: where things live in the repository, how to build and preview the book, and the cross-cutting files every manual touches.

- [Repository layout](060-reference/010-repository-layout.md) (*always read*): The book, manuals, and helpers tree; folder responsibilities; and the high-value items inside helpers/ to reuse before drawing or writing anything new, including the textbook source and the Belay voltammetry rig. AGENTS.md section 3 before the split.
- [Build and preview](060-reference/020-build-and-preview.md): Build and serve with run_book_server.sh or jupyter-book build book/; a clean build must succeed, and a warning is acceptable only beside a TODO flag. AGENTS.md section 8 before the split.
- [Cross-cutting reference material](060-reference/030-cross-cutting-reference-material.md): The table of contents, build config, global CSS, book landing page, and admonition gallery, and what to update when a manual or admonition is added. AGENTS.md section 9 before the split.
